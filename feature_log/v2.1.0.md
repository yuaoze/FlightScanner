# FlightScanner v2.1.0 更新说明

**发布日期**: 2026-07-20

**版本**: v2.1.0

---

## 版本概述

v2.1.0 聚焦在三件事：让监控更精准、让周末雷达更稳、更好地把已有功能整理成一次正式发布。除了新增按航班号固定监控外，这次也补强了去哪儿国际单程兜底路径、Cookie 扫码登录兼容性，以及周末雷达的扫描节奏、目的地覆盖和前端可见性。

---

## 一、监控能力增强

### 1.1 精准航班监控

前端新增“路线监控 / 精准航班监控”双模式：

- 添加监控时可切换到 **精准航班监控**
- 支持填写 **去程航班号**、可选 **回程航班号**、以及 **舱位筛选**
- Dashboard 卡片在固定航班模式下展示航班号 badge，便于快速识别

涉及文件：

- `frontend/src/pages/AddMonitorPage.tsx`
- `frontend/src/components/dashboard/AddMonitorDialog.tsx`
- `frontend/src/components/dashboard/MonitorCard.tsx`
- `frontend/src/types/index.ts`

### 1.2 Dashboard 快捷添加监控

监控总览页增加弹窗式「＋ 添加监控」，减少从总览跳转到独立创建页的操作成本。

涉及文件：

- `frontend/src/pages/DashboardPage.tsx`
- `frontend/src/components/dashboard/AddMonitorDialog.tsx`

## 二、抓取与兼容性修复

### 2.1 去哪儿国际单程回退路径

针对国际单程在 `oneway_list_inter.htm` 的 `wwwsearch` 接口返回空结果的情况，新增回退逻辑：

- 自动构造一个“假往返”请求
- 改走 `interroundtrip_compare` 相关路径取回数据
- 最终只保留去程单腿结果返回

这让部分被风控或返回空数据的国际单程线路仍然能得到可用价格，尤其有利于周末雷达的目的地扫描覆盖率。

涉及文件：

- `src/flightscanner/scrapers/qunar_scraper.py`

### 2.2 Cookie 扫码登录路径兼容

修复从 `frontend/` 或其他非项目根目录启动时，扫码登录线程找不到 `scripts.qunar_login` / `scripts.ctrip_login` 的问题。现在会在启动登录线程前补齐项目根目录到 `sys.path`。

涉及文件：

- `src/flightscanner/api/routers/cookies.py`
- `ui/components/cookie_manager.py`

## 三、周末雷达升级

### 3.1 扫描稳定性增强

周末雷达扫描器新增多项稳定性改进：

- 单次搜索支持 **多 scraper 顺序 fallback**
- 目的地之间请求间隔从固定 0.5s 调整为 **随机 2–5s**
- 去程与回程之间增加随机等待，降低连续命中风控的概率
- 跨周末批量扫描前主动关闭 scraper 浏览器状态
- 周末之间增加 **40–90s 冷却时间**

这些调整主要用于缓解长时间连续扫描导致的浏览器累积状态、内存压力和风控命中问题。

涉及文件：

- `src/flightscanner/weekend_radar/scanner.py`
- `src/flightscanner/scheduler/price_monitor.py`

### 3.2 目的地池扩容

国际/港澳台池增加：

- 日本：福冈、名古屋、冲绳
- 韩国：釜山
- 东南亚：清迈、河内、胡志明市、岘港

同时补充了对应的签证说明、视觉 emoji、渐变色和封面图资源。

涉及文件：

- `src/flightscanner/weekend_radar/destinations.py`

### 3.3 前端周末可见性优化

雷达筛选区现在始终展示未来 8 个周末，即使某些周末尚未扫描或当前没有 deal，也会保留为 `0`。这样用户能更早看到完整时间范围，而不是只能看到缓存里已有数据的周末。

涉及文件：

- `src/flightscanner/api/routers/radar.py`
